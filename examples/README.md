# Examples

Examples are explanatory and non-normative.

- `v1/` demonstrates Core V1 package behavior, including opaque Semantic V1
  dispatch.
- `semantic/v1/` contains complete Semantic V1 design scenarios with template
  packages, responses, expected expanded JSON-LD, and expected diagnostics.

Design examples become normative fixtures only after the corresponding
specification, JSON Schema, validation rules, diagnostics, and projection
algorithm are frozen.
