# Conformance fixtures

- [`v1/`](v1/README.md) contains Core V1 packages, invalid cases, and
  application-capability evidence.
- [`semantic/v1/`](semantic/v1/README.md) contains portable Semantic V1
  projection inputs, expected expanded JSON-LD graphs, and diagnostics.

Fixtures are data contracts rather than JavaScript test cases. Consumer
applications may run them with their own validators and projectors.
