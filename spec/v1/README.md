# MARKER Metadata Template Specification V1

> **Status:** Draft and non-normative

This directory will contain the authoritative human-readable V1
specification.

Core V1 will define:

- the MARKER Template Document;
- draft and published template metadata;
- the MARKER Form Schema Profile;
- the MARKER UI Schema Profile;
- component and cross-component validation;
- RJSF compatibility;
- Form Studio round-trip compatibility; and
- conformance and diagnostics.

The Semantic Extension and metadata-instance JSON-LD projection will be
specified after Core V1 no longer blocks the first STAPLE-to-MARKER import.

Do not add a normative identifier or claim V1 conformance until the schemas and
conformance fixtures are complete.
